# AssetCraft decision registry

The project owner approves decisions. A proposal authorizes work only within the scope explicitly approved by the owner.

Statuses are `PROPOSED`, `UNDER REVIEW`, `APPROVED`, `REJECTED`, `DEFERRED`, and `SUPERSEDED`.
