# Shared library matrix

This initial audit uses the [D01 evaluation revision](../decisions/REGISTRY.md). The workspace declares MIT OR Apache-2.0. The matrix records source evidence and proposed use. The [D03 Linux prototype](artcraft-alignment.md#d03-linux-prototype-results) verified a subset. Project feature selection and licensing decisions remain open.

| Capability | Candidate and proposed use | Verification needed |
| --- | --- | --- |
| Native runtime | Reuse `craft` with `ui-app` and `ShellApp`. [Facade](https://github.com/storytold/craft-libs/blob/90e14375a4a461fb42eba802846250b2473366f7/crates/craft/Cargo.toml) | Open a native window and verify focus, lifecycle and feature resolution. |
| Grid and thumbnails | Reuse `craft::ui::tile_grid::TileGrid` and `craft-browse` with `browse` and `ui`. Compare direct grid use with `MediaBin`. Adapt `FileThumbSource` to asset IDs. [Browser](https://github.com/storytold/craft-libs/tree/90e14375a4a461fb42eba802846250b2473366f7/crates/browse) · [Grid tests](https://github.com/storytold/craft-libs/tree/90e14375a4a461fb42eba802846250b2473366f7/crates/ui-widgets/tests/it/tile_grid) | Check async thumbnail delivery, keyboard selection, viewport work and the cost of enumerating catalog items. |
| Host services | Reuse `Host::builder`, `Files`, `Jobs`, `Commands` and `JobQueue`. Evaluate native dialogs and settings for preferences. [Host](https://github.com/storytold/craft-libs/tree/90e14375a4a461fb42eba802846250b2473366f7/crates/host) | Check cooperative cancellation, queue limits and stale results. |
| Design and accessibility | Reuse shared components, semantic theme roles, translation support and upstream design lint. Evaluate `theme-store` for shared preferences. [Design tools](https://github.com/storytold/craft-libs/blob/90e14375a4a461fb42eba802846250b2473366f7/crates/design-lint/README.md) · [Accessibility standard](https://github.com/storytold/craft-contrib/blob/e0bf5c9a60fc25b61fd7c1f4f4efb8cea33b3c8b/standards/accessibility.md) | Verify focus, announcements, control semantics and both themes. |
| Image inspection | Reuse `craft-file-formats::detect`, `craft-image-codecs::decode_with` and `craft-metadata::extract`. PNG and JPEG are initial candidates. [Codecs](https://github.com/storytold/craft-libs/tree/90e14375a4a461fb42eba802846250b2473366f7/crates/image-codecs) | Establish bounded decoding and caching. Verify malformed inputs, metadata and each claimed format. |
| Catalog and recovery | Implement application policy for stable IDs, associations, search, deduplication, trash and recovery. Evaluate `craft-atomic` for single-file writes. `craft-sqlite` provides file-format helpers. [Atomic](https://github.com/storytold/craft-libs/tree/90e14375a4a461fb42eba802846250b2473366f7/crates/atomic) · [SQLite helpers](https://github.com/storytold/craft-libs/blob/90e14375a4a461fb42eba802846250b2473366f7/crates/sqlite/src/lib.rs) | Compare storage choices and demonstrate consistency across catalog and original files under interrupted writes. |
| IPC and public automation | Defer the app provider and MCP decision. `craft-ipc` documents authenticated discovery, asset monikers and the `assets` capability. [IPC protocol](https://github.com/storytold/craft-libs/blob/90e14375a4a461fb42eba802846250b2473366f7/crates/ipc/PROTOCOL.md) | Verify a real peer before claiming integration. Review file-root enforcement before enabling MCP. |
